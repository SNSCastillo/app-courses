# Configuración

Documenta aquí los archivos y procesos de configuración del proyecto:

- `app.json`: configuración de Expo, plataformas, iconos y plugins.
- `package.json`: dependencias y comandos npm.
- `tsconfig.json`: opciones de TypeScript y alias de importación.
- `biome.json`: formato y análisis estático.

Los directorios nativos `ios/` y `android/` se generan cuando hacen falta; no se versionan ni se editan manualmente en este proyecto.
