# Arquitectura

Documenta aquí la estructura de la aplicación, navegación, patrones compartidos y decisiones técnicas.

- Las rutas y pantallas viven en `src/app/`.
- Los componentes reutilizables viven en `src/components/`.
- Las reglas de negocio deben organizarse por dominio en `src/` cuando se incorporen.
- Registra decisiones importantes como documentos breves con contexto, decisión y consecuencias.
