# App Courses

Aplicación multiplataforma para cursos, creada con Expo SDK 57, React Native y Expo Router

## Desarrollo

```bash
npm install
npm run start
```

También puedes iniciar directamente en una plataforma:

```bash
npm run android
npm run ios
npm run web
```

## Comprobaciones

```bash
npm run typecheck
npm run lint
```

## Estructura

- `src/app/`: pantallas y rutas.
- `src/components/`: componentes reutilizables y navegación.
- `src/constants/`: temas y valores compartidos.
- `src/hooks/`: hooks de la aplicación.
- `assets/`: imágenes e iconos.
- `docs/`: documentación del proyecto.

Organiza en `docs/` la documentación técnica, decisiones y guías conforme el proyecto crezca.
